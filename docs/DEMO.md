# Acessos de demonstração

Estes acessos funcionam apenas no protótipo local/GitHub Pages e não devem ser usados em produção.

- Administrador Nexus: `admin.demo@nexuscore.local` / `NexusDemo#2026`
- Técnico de SST: `tecnico.demo@empresa-alfa.local` / `SstDemo#2026`
- Diretor: `diretor.demo@empresa-alfa.local` / `DiretorDemo#2026`

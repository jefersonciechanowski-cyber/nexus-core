# Nexus Core

Monorepo inicial do ecossistema Nexus Core Tecnologia LTDA.

## Testar localmente
Abra `apps/sst-controle/login.html` no navegador ou execute um servidor estático.

## Demonstração
Consulte `docs/DEMO.md`.

## Publicação
O workflow `.github/workflows/pages.yml` publica o repositório no GitHub Pages após push para `main`.

## Próximas etapas
Site de captação, Supabase/Auth, confirmação de pagamentos, Portal do Cliente e Nexus Admin.
